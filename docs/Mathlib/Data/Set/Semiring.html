    Sets as a semiring under union #

    This file defines SetSemiring α, an alias of Set α, which we endow with ∪ as addition and pointwise * as multiplication. If α is a (commutative) monoid, SetSemiring α is an idempotent (commutative) semiring.

    An alias for Set α, which has a semiring structure given by ∪ as "addition" and pointwise multiplication * as "multiplication".
