    Constructing a measure from an outer measure #

    Given m an outer measure over α, we construct a measure m.toMeasure for a measurable space ms ≤ m.caratheodory, by defining m.toMeasure s = m s when MeasurableSet s.

    Main definition #

    • OuterMeasure.toMeasure: Obtain a measure by giving an outer measure where all sets in the σ-algebra are Carathéodory measurable.
