    Continuity of measures #

    This file proves several versions of continuity from above and continuity from below of measures, namely statements of the form μ (⋃ n, s n) = ⨆ n, μ (s n) and μ (⋂ n, s n) = ⨅ n, μ (s n) for s : ℕ → Set α.
