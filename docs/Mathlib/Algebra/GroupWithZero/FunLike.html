    Group with zero instances for FunLike types #

    In this file we define various instances related to GroupWithZero for FunLike types. There are two different variants: either the multiplication is given by composition or it is pointwise multiplication.

    Note that currently, these are not registered as instances, but only abbrevs to avoid long typeclass searches.
