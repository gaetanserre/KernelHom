    Implementation of the unlift_eq tactic for kernels. #

    This file registers the unlifting of lifted kernel expressions for the unlift_eq tactic, with the same lemmas as the lifting.

    Main declarations #

    • unliftKernelExpr: recursive unlifting of a lifted kernel expression.

      Recursive unlifting of a kernel e lifted to the universe w. Returns the unlifted kernel e' together with a proof of e = e'.lift. Each step is a single application of a lifting lemma, given the unliftings of the subterms.
