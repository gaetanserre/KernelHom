    Kernel lifting utilities #

    This file provides helper functions for lifting and unlifting kernel expressions: type extraction, construction of measurable equivalences, and explicit constructors for kernel operations and Kernel.lift. The constructors build the applications directly (mkAppN with explicit universe levels and instances) instead of going through mkAppM, whose unification is the main cost of the transformations.

    Main declarations #

    • Carrier: a measurable space X : Type u, given by the expression X and the level u.
    • getTypesFromKernel: extracts carrier types and universe levels from kernel expressions.
    • constructMeasurableEquiv: recursively builds measurable equivalences.
    • getOriginalType: retrieves the original type from a lifted type.
    • mkKernelComp, mkKernelParallelComp, ..., mkKernelLift: explicit constructors.
