    measure_kernel tactic #

    This file implements the measure_kernel tactic, which transforms equalities of measures into equivalent equalities of kernels from Unit.

    The translation sends a measure μ to its constant kernel Kernel.const Unit μ, and the operations on measures to operations on kernels:

    MeasureKernelLemma
    κ ∘ₘ μκ ∘ₖ KKernel.comp_const_of_eq
    μ ⊗ₘ κ(Kernel.id ×ₖ κ) ∘ₖ KKernel.id_prod_comp_const_of_eq
    μ.prod νK ×ₖ LKernel.prod_const_of_eq
    any other μKernel.const Unit μreflexivity

    where K and L are the translations of μ and ν. The translations of ⊗ₘ and Measure.prod need the measures and the kernel to be s-finite; otherwise, the measure is translated as an atom. Measure.map is not translated.

    Main declarations #

    • measureToKernel: recursive translation from measure expressions to kernel expressions.
    • KernelEquality: core implementation of measure_kernel on an equality.
    • measure_kernel: user-facing tactic (with location support).

          Recursive translation of a measure e : Measure X into a kernel e' : Kernel Unit X. Returns e' together with a proof of e' = Kernel.const Unit e. Each step is a single application of a translation lemma, given the translations of the subterms (Kernel.comp_const_of_eq, ...). A measure that is not built from the operations of the table above, or whose instances cannot be found, is translated as an atom.

            def MeasureKernel.measureKernel :
            Lean.ParserDescr

            The measure_kernel tactic transforms a measure equality to an equivalent equality of kernels from Unit.

            The tactic supports location specifiers like rw or simp:

            • measure_kernel — applies to the goal
            • measure_kernel at h — applies to hypothesis h
            • measure_kernel at h₁ h₂ — applies to multiple hypotheses
            • measure_kernel at h ⊢ — applies to hypothesis h and the goal
            • measure_kernel at * — applies to all hypotheses and the goal

            Example:

            example {X : Type*} [MeasurableSpace X] (μ ν : Measure X) (h : μ = ν) : ν = μ := by
  measure_kernel at h ⊢
  exact h.symm
