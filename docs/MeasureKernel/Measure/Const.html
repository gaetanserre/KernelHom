    Measures as kernels #

    This file defines the transformation between measures and kernels from Unit, through the constant kernel Kernel.const Unit μ.

    Main declarations #

    • Kernel.const_congr: two measures are equal if and only if their constant kernels are equal.
    • Kernel.id_prod_comp_const: the composition-product μ ⊗ₘ κ as a composition of kernels.
    source
    theorem ProbabilityTheory.Kernel.const_congr {X : Type u_1} [MeasurableSpace X] (μ ν : MeasureTheory.Measure X) :
    μ = ν ↔ const Unit μ = const Unit ν

    theorem ProbabilityTheory.Kernel.const_congr_of_eq {X : Type u_1} [MeasurableSpace X] {μ ν : MeasureTheory.Measure X} {κ η : Kernel Unit X} (hκ : κ = const Unit μ) (hη : η = const Unit ν) :
    (μ = ν) = (κ = η)

    The equivalence between an equality of measures and the equality of their translations κ and η, given by const_congr.

    (Kernel.id.prod κ).comp (const Unit μ) = const Unit (μ.compProd κ)

    The composition-product of a measure and a kernel, as a composition of kernels from Unit.

    Translation lemmas with hypotheses #

    The translation lemmas, with the translations of the subterms given as hypotheses. They are used by the measure_kernel and kernel_measure tactics, so that each step of the translation is a single application of these lemmas.
